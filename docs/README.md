# Documentation

Durable scientific and teaching specifications.

- `workshop_plan.md`: authoritative audience, schedule, feature roles, notebook sequence, and unresolved decisions.
- `notebook-00-instructor-complete-plan.md`: cell-level plan for the self-contained morning and afternoon instructor handouts.
- `data_dictionary.md`: planned definitions, units, allowed values, missing-value meanings, and source for every field.
- source documentation: planned download sources, versions, checksums, tool parameters, and identifier-resolution decisions.
- instructor notes: planned timing, facilitation, backup workflow, and expected outputs.

Update documentation whenever a scientific definition, file schema, or workshop decision changes.
