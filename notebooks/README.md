# Workshop notebooks

Google Colab materials distributed to students and instructors.

Planned pairs:

- `01_sequence_features_student.ipynb` and instructor solution;
- `02_decision_tree_student.ipynb` and instructor solution;
- `03_candidate_challenge_student.ipynb` and instructor solution.

Every exercise requires a synchronized instructor solution and a deterministic behavioral test. Student notebooks must not contain answer code in cells, comments, outputs, metadata, or collapsed content. Both versions must run top to bottom after restarting a clean Colab runtime.

Notebooks load canonical data from `../input/processed/`; do not embed duplicate datasets or make notebooks the only implementation of data preparation.
