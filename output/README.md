# Generated output

Regenerable products from a specific pipeline or analysis run, such as figures, quality-control reports, logs, evaluation summaries, and ranked candidate lists.

Do not store raw data or the canonical student/instructor tables here. Those belong under `../input/`. Each important output should record or link to the script, configuration, and processed inputs that generated it.

Raw predictor outputs belong in `../input/raw/predictors/`, parsed reusable
features in `../input/processed/`, and classification outcomes, agreement reports,
figures, and run-specific quality-control summaries here.
