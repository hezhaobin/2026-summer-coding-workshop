# Tests

Automated tests for scripts, feature functions, parsers, joins, and notebook exercises.

Use tiny synthetic or redistributable fixtures rather than copying full proteomes. Tests should cover manually checkable S/T calculations, short and invalid sequences, parser schema changes, duplicate or unmatched identifiers, selective-feature missingness, and prevention of accidental zero-filling.

Every student exercise must have a behavior-based test that does not disclose the solution and passes against the instructor implementation.
