# Demo predictor results

Immutable SignalP 6.0 and NetGPI 1.1 outputs for the workshop's embedded
*Candida albicans* ALS1 and PHO84 examples.

Each dated directory contains the saved complete-results webpage, its adjacent
browser asset directory, the machine-readable result files recovered from the
temporary job URL, and a `source-info.json` record. Keep each HTML file beside
the `_files/` directory with the same original filename stem if opening the
complete page locally.

The complete pages are retained for instructor review and source fidelity. The
student-facing interpretation backup is `docs/demo-predictor-results.md`; it
uses only the saved summaries and four result plots, because GitHub does not
render the complete interactive page bundles reliably.
