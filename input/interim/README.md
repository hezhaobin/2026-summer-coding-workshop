# Interim data

Regenerable working data produced from `../raw/`, including normalized FASTA files, identifier inventories and maps, parsed tool outputs, two-of-three eligibility lists, and join diagnostics.

Files here may be replaced by scripts. Each file should identify the script, configuration, and raw inputs that produced it. Do not use interim data as the final student dataset.

`fungalrv_2011/` is generated by `script/import_fungalrv_legacy.py` and contains
the normalized stable-ID FASTA, sequence header-information extract, and brief KN identifier-match
table.
